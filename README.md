# xrwvm-fullstack_developer_capstone

## Full Stack Developer Capstone Project

This project is a car dealership web application built with:

- **Frontend**: React.js
- **Backend**: Django (Python)
- **Database**: SQLite (Django) + MongoDB (Node.js/Express)
- **Sentiment Analysis**: NLTK deployed on IBM Code Engine
- **Containerization**: Docker + Kubernetes
- **CI/CD**: GitHub Actions with ESLint and Flake8 linting
